# Bitcoin public wallets

Polion accepts Bitcoin mainnet public wallet expressions. A bare `xpub` is interpreted as a native SegWit account public key and scans its receive (`0`) and change (`1`) branches. Confirm this script type and account level with the exporting wallet; an xpub alone does not identify its intended output script or derivation path.

Supported descriptors are `addr(ADDRESS)`, `pkh(KEY)`, `wpkh(KEY)` and `sh(wpkh(KEY))`. `KEY` is a mainnet xpub, optionally preceded by a key origin such as `[deadbeef/84h/0h/0h]`, followed by unhardened numeric derivation steps and optionally one final `*` wildcard. The origin is descriptive; derivation begins at the supplied xpub. A descriptor describes one branch. Import separate descriptors for receive and change if needed. Optional eight-character descriptor checksums are validated. Other script expressions, multipath syntax, private keys, hardened derivation after the xpub, and alternate extended-key versions are rejected.

Discovery queries the configured Esplora endpoint for each derived public address after source consent. For each branch it stops after a configurable gap of consecutive unused addresses (20 by default), retaining all scanned addresses as child targets for subsequent refreshes. It revisits the previously scanned range on later discovery. A bounded scan that cannot establish its gap fails without changing the child targets. The gap is an assumption: addresses beyond a run of unused addresses can contain funds, so choose a suitable gap and rediscover as the wallet is used. An `addr` descriptor queries its single address. The provider learns the queried addresses and can return incomplete or incorrect data.

Public derivation follows [BIP 32](https://github.com/bitcoin/bips/blob/master/bip-0032.mediawiki), descriptor checksums follow [BIP 380](https://github.com/bitcoin/bips/blob/master/bip-0380.mediawiki), and native SegWit wallet vectors are checked against [BIP 84](https://github.com/bitcoin/bips/blob/master/bip-0084.mediawiki). The test account xpub in `BitcoinWalletTest` is the BIP 84 account public key with its serialization version changed from zpub to xpub; its receive and change addresses are checked against the published vectors.
