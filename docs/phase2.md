# Exact money and identity decisions

Domain IDs are distinct validated string value types. Network identity is part of the caller's canonical asset or target identity; symbols are not IDs. ExactInteger stores canonical signed base-10 integers and ExactDecimal stores a coefficient and nonnegative scale. Their plain decimal string representations round-trip independently of locale. Decimal scale is retained for serialization; numeric comparison aligns scales. Arithmetic remains exact; rescaling requires an explicit rounding rule. Atomic conversion rejects fractional atomic units. Asset quantities cannot be combined across asset IDs. Price multiplication produces an exact quote quantity with no implicit rounding. Persistence and richer price provenance are introduced by subsequent phases.
